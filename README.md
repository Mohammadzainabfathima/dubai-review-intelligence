# Dubai Review Intelligence

Bilingual (Arabic / English / mixed) customer-review analysis for Dubai hospitality and retail.
Course: MAAI 902 – Natural Language Processing & LLMs, University of Wollongong in Dubai.

## What it does
Reads reviews written in Arabic, English or a mix of both and produces a short briefing a manager can act on:

1. **Pre-processing** – Arabic normalisation, PII masking, script-based language detection, clause splitting.
2. **Sentiment** – three models compared: TF-IDF + logistic regression (baseline), multilingual XLM-R sentiment (zero-shot), and XLM-RoBERTa fine-tuned by us.
3. **Aspect sentiment** – bilingual lexicon finds aspects (service, staff, food, price, cleanliness, room, location, facilities) inside each clause; the sentiment model scores the clause.
4. **Complaint clustering** – multilingual sentence embeddings + k-means (k by silhouette) with c-TF-IDF theme terms.
5. **Grounded LLM briefing** – the LLM only sees an evidence pack and must cite review IDs; an automatic check verifies every citation and number (hallucination mitigation).
6. **Semantic search (retrieval)** – FAISS index over review embeddings ("ask your reviews").

```
reviews -> clean -> language -> sentiment -> clauses+aspects -> embeddings -> clusters
                                                                      |           |
                                                         FAISS search <-          v
                                               evidence pack -> LLM briefing -> faithfulness check
```

## Quick start (Google Colab, recommended)
1. Open `Dubai_Review_Intelligence.ipynb` in Colab and choose **Runtime > Change runtime type > T4 GPU**.
2. Upload this repo as a zip (or `git clone` it) and run the cells top to bottom.
3. The last cell launches the Gradio demo and prints a public link.

## Get the data
Put two CSV files in `data/` (they are not committed because of dataset licences):

| File | Suggested source | Columns used |
|---|---|---|
| `arabic_reviews.csv` | Kaggle "Arabic 100k Reviews" (or HARD / LABR) | review text, label |
| `english_reviews.csv` | Kaggle hotel reviews or Yelp reviews | review text, rating |

Adjust `AR_TEXT`, `AR_LABEL`, `EN_TEXT`, `EN_LABEL` in the notebook to match the column names. Stars 1–5 map to negative (≤2), neutral (3), positive (≥4); `Positive/Negative/Mixed` words are mapped automatically.
Synthetic code-switched reviews are generated by pairing an Arabic and an English review with the same label (documented as augmentation).

## Run locally
```bash
pip install -r requirements.txt
python tests/test_core.py          # model-free tests
python app.py                      # demo (downloads models on first run)
```
Optional: `export ANTHROPIC_API_KEY=...` for the Claude summary backend; otherwise a deterministic template summary is used, or choose `local` for an open Hugging Face model.

## Evaluation
Accuracy, macro-F1 (with 95% bootstrap CI), per-language F1 (Arabic / English / mixed), confusion matrices, a 40-review error analysis, and the summary faithfulness score. Results are written to `results/`.

## Ethics (summary)
Dialect and language bias (checked with per-language F1), reviewer privacy (PII masking, no raw data committed), fake or manipulated reviews, LLM hallucination (evidence-only prompt + automatic checking), and human-in-the-loop use (the tool supports managers; it does not make decisions about staff). See the report for details.

## Limitations
Aspect detection is keyword-based and misses implicit aspects; public training data is not Dubai-specific; synthetic code-switched data only approximates real mixed-language writing.
